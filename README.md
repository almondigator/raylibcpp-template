# Raylib 6.0 C++ Template
## Prerequisites (Linux)

```bash
sudo apt update
sudo apt install libasound2-dev libx11-dev libxrandr-dev libxi-dev libxcursor-dev libxinerama-dev libxkbcommon-dev
```

# Building and running
```bash
make        # build and run
make build  # compile changes only
make clear  # remove build folder
make run    # execute the current binary
```
